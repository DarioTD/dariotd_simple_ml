Feed-forward Neural Network
===========
DarioTD's FFN


Install
-------
To install run `cargo install --path .`

Run
-------
To run `cargo run`

Uninstall
---------
To uninstall run `cargo uninstall`

History
-------
This project started as an experiment while learning Rust and exploring perceptrons and neural networks. The initial implementation followed ideas from a C implementation presented by Tsoding, but was progressively reimplemented, refactored and extended in Rust and curiosity.
The project also motivated further exploration of perceptron's activation functions, optimization and the mathematics behind neural networks.
